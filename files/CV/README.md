# Kartik Loya CV

Kartik_Loya_CV.pdf is the website download. Kartik_Loya_CV.typ is the editable source, based on the continuous RenderCV version. The PNG files preview its three pages.

Portfolio: https://kloya03.github.io/kloya.github.io/

Rebuild using the Typst CLI:

    typst compile Kartik_Loya_CV.typ Kartik_Loya_CV.pdf

This source uses @preview/rendercv:0.3.0. After changes, rebuild the website with node scripts/build.mjs from the repository root. The legacy files/Kartik_Loya_CV.pdf is retained for existing links; update that copy too when rebuilding the CV.
